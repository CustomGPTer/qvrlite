# QVRLite

QVRLite is a smaller, simpler QVR for Android. One tap starts recording, another saves it. No internet access, no location, no adverts. It installs alongside QVR. In beta.

Website: https://customgpter.github.io/qvrlite/

Download: https://github.com/CustomGPTer/qvrlite/releases/download/v1.0.0-beta1/QVRLite.apk
