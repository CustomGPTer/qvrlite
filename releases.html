Release notes

What changed in each version of QVRLite. The newest is at the top.

Version 1.0.0 beta 1 21 November 2026Latest

  • First test build.
  • One-tap recording icons and widgets, camera and lens choice, pause and resume, quality and sound settings.
  • Time and file-size limits with repeat, and dashcam mode.
  • PIN lock, private storage, and a recordings list with previews, export and bulk delete.

Checking your download

The file for version 1.0.0 beta 1 is called QVRLite.apk. It is 0.47 MB (468,639 bytes). Its SHA-256 checksum is:

aa6552c2908411145caa5dd66d1484aac2357ac0eb671b90e70d5bddc3ec5842

On Windows, run certutil -hashfile QVRLite.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
